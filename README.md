# 像素股市：开盘前夜

一个纯前端、像素风格的股票交易小游戏。你将扮演一名新手交易员，在每天 09:00–21:00 的交易室工作中观察行情、买卖股票、应对随机事件和客户电话，并通过升级与完成目标逐步提升资产与声誉。

## 在线仓库

<https://github.com/jay-jr-z/jay-de-repy>

## 运行方式

项目没有构建步骤或第三方依赖，直接用浏览器打开 `index.html` 即可游玩。

也可以在项目目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 玩法特色

- 三家公司可交易：方块电池、青柠云工厂、红砖机器人
- 实时价格波动、历史价格曲线与随机市场事件
- 买入、卖出、持仓和资产净值管理
- 客户电话与邮件系统：选择不同回答影响现金、经验、声誉和市场情绪
- 每日总结、月底解锁新公司，以及循序渐进的难度选择
- 能力树升级交易桌、分析和服务；完成手动训练后解锁 AI 商店
- 响应式界面，支持桌面和移动端浏览器

## 操作提示

1. 开机后按照引导观察行情，完成三次观察。
2. 完成至少一次买入和一次卖出，熟悉交易流程。
3. 留意右下角随机事件和来电，它们可能改变股价或奖励条件。
4. 在升级中心依次点亮能力树，完成当前目标后再挑战更高难度。
5. 每天 21:00 生成总结；合理控制仓位，避免现金耗尽。
